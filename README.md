# PecuCalc — Calculadora de Resultados Pecuários 2025

Webapp standalone para cálculo de custos, receita e ponto de equilíbrio em operações de pecuária bovina. Desenvolvido para uso em desktop e mobile, sem dependência de backend ou banco de dados.

## Funcionalidades

- **Cenário 1** — Lotes com uma suplementação (Proteinado)
- **Cenário 2** — Lotes com duas suplementações (Recria + Engorda)
- **Comparativo** — Análise lado a lado dos dois cenários
- **Ponto de Equilíbrio** — Simulador mês a mês com gráfico interativo

## Como usar

Acesse via GitHub Pages após o deploy. Não requer instalação, login ou conexão com banco de dados.
